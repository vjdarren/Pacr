# Product Overview

## App Name
Pacr

## Tagline
run smarter. recover better. go further.

## Core Idea
Pacr is a recovery-first AI running coach powered by Huawei Health data.

## Mission
Make elite-level running coaching accessible to everyday runners.

## Core Principles
- Recovery-first coaching
- Adaptive training
- Low cognitive load
- Science-backed recommendations
- Clear and motivating UX

## Key Features
- Adaptive training plans
- Readiness scoring
- AI coach
- GPS run tracking
- Analytics dashboard
- Huawei Health integration
