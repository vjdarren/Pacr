# Brand System

## Design Style
Dark Sport Minimal

## Brand Voice
Direct, encouraging, data-informed.

## Tone Rules
- Never patronising
- Never overly clinical
- No guilt-tripping
- Clear and confident

## Primary Colors
- Coral: #FF5733
- Dark Background: #0F1F3D
- Surface: #1A3260

## Typography
- Inter ExtraBold
- Inter Bold
- Inter Regular

## UX Principles
- Minimal clutter
- Actionable insights only
- High contrast
- Accessibility-first
